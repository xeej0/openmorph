How is this private?

      
OpenMorph is a static web page. All conversion happens with code that runs inside your browser (Canvas, pdf-lib, PDF.js and ffmpeg.wasm). There is no server that receives your files. Open your browser's developer tools and watch the Network tab: your files are never sent anywhere.
